설정

GitHub 토큰에 현재 저장소의 Contents·Actions 쓰기 권한을 부여하고 연결하세요. 토큰은 현재 페이지 메모리에만 보관됩니다.

사용

  1. .blend 또는 ZIP·GLB·PNG를 선택합니다.
  2. 씬을 선택하고 배치에 추가합니다.
  3. 배치를 저장합니다. 전체 조명 계산과 6시점 비교가 자동 실행됩니다.

검증을 통과한 최신 배치는 새 3D 페이지에 반영됩니다. 미달·실패 시 이전 결과를 유지합니다. 기존 /, /v2/, /clay/는 유지됩니다.

제작 파일

Blender 3.6 Cycles, 활성 카메라, 불투명 배경. 외부 이미지는 패킹하고 링크·인스턴스는 실체화하세요. 저장된 현재 프레임을 사용합니다. 제작자가 미리 베이킹할 필요는 없습니다.

전체 씬 하나가 한 모듈입니다. RoomLights에는 모듈별 조명, StudioLights에는 공통 조명을 넣으세요. 새 방식은 WebBake 지정 여부와 관계없이 모든 렌더 가능 표면을 계산합니다. 단일 모듈은 원본 바닥을 유지하며 여러 모듈은 공통 바닥과 첫 모듈의 World를 사용합니다.

볼륨·홀드아웃·임의 합성 효과·새 버전의 .blend는 호환성 검사에서 중단됩니다. 유리와 날카로운 반사는 근사이므로 검증에서 보류될 수 있습니다.

한도

업로드 파일당 48MiB, 합계 180MiB·100개. 생성 3D 파일은 최대 96MiB. 배치 1~6모듈, 원본당 4,000메시, 전체 12,000메시·300만 삼각형. 작업 최대 360분. 텍스처와 재질 복잡도에 따라 한도 안에서도 처리가 어려울 수 있습니다.

공개 저장소의 원본과 버전 이력은 공개됩니다. 연결 없이 저장한 파일은 이 브라우저에만 남습니다.

설치

다른 저장소에는 이 저장소의 admin/, clay/, studio/ 코드, tests/validate-radiance.mjs, 패키지 파일과 변환 워크플로를 함께 설치하세요. 워커만 복사하면 웹 검증을 실행할 수 없습니다.
