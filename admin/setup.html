GitHub 연결

현재 사이트 저장소에는 변환 워크플로가 설치되어 있습니다. GitHub 토큰에 해당 저장소의 Contents와 Actions 쓰기 권한을 부여하고 Studio에서 연결하세요. 토큰은 현재 페이지 메모리에만 보관됩니다.

사용

  1. ZIP 또는 GLB·PNG·.blend를 선택합니다.
  2. 모델과 원본을 확인하고 ‘배치에 추가’를 누릅니다.
  3. 격자·회전·바닥을 정하고 ‘배치 저장·베이킹’을 누릅니다.
  4. GitHub Actions가 전체 간접광을 계산하고 결과를 저장합니다.

현재 저장소의 최신 배치가 완료되면 /clay/에 자동 반영됩니다. 계산 중이거나 실패하면 마지막 완료 결과를 유지합니다. 기존 / 페이지는 변경되지 않습니다.

입력

전체 씬 하나가 모듈 하나입니다. Cycles .blend에 외부 이미지를 패킹하고 사용할 씬을 선택하세요. v06 ZIP은 전체 Normal 씬이 자동 선택됩니다. 파일당 48MiB, 전체 180MiB·100개까지 지원합니다.

배치 1~6개, 원본당 메시 4,000개, 전체 메시 12,000개·삼각형 300만 개, 결과 GLB 48MiB가 상한입니다. 작업 제한은 90분이며 실제 처리 가능 크기는 재질과 UV 복잡도에 따라 달라집니다. 볼륨·절차적 인스턴스·비메시 오브젝트는 미리 메시로 정리해 주세요.

베이킹

WebBake 컬렉션에 고정된 무광 표면(트랙 선·매트 포함)을 넣으세요. 해당 표면과 공용 바닥에는 전체 배치의 직접광·간접광·그림자가 저장됩니다. 의자 등 그림자를 만드는 소품은 원래 위치에 두세요. RoomLights는 모듈을 따라가고 StudioLights는 한 세트만 사용합니다. 두 조명 컬렉션 중 하나를 쓰면 미지정 광원은 방 조명으로 처리합니다. 컬렉션이 없는 기존 파일은 기존 자동 분류를 사용합니다.

다른 무광 표면의 간접광을 선형 RGBM 라이트맵으로 저장하고, 색·노멀·거칠기는 별도 PBR 텍스처로 유지합니다. 직접 조명과 표면 반사는 웹에서 계산합니다. 기본 2K·96샘플, 정밀 2K·256샘플이며, UV가 들어가지 않으면 묶음을 자동 분할합니다. 배치·조명·구조가 바뀌면 다시 저장하세요. 면광원·유리·반사는 Blender와 차이가 남을 수 있습니다.
